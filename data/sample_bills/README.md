# Sample bills

Hand-made demo fixtures used for OCR tests (§9.1) and the live demo. Put bill
images here, grouped by language:

- `es/` — Spanish-language bills
- `zh/` — Chinese-language bills
- `ko/` — Korean-language bills

Each is a fictional bill (e.g. "Comcastic Internet") with known ground-truth
values for the OCR test. These are NOT real customer bills — see the honesty
notes in the README and PDR §7.6.
